# Integration prep — patch, spec f54d0bc (multi-host daemons, native install, LLM-agnostic backends)

Plan: `spec/plans/2026-08-04T18-11-14-f54d0bc-plan.json`

What this change makes host-shaped, and therefore what has to exist locally before a build
agent can honestly test it end to end:

- two daemons against one server (B1, D1, D2, I1)
- a daemon installed from a built, signed artifact onto a machine with only an OS (A2, B2, C5, E3, G1)
- backend provisioning — present / absent / logged-out (C2)
- per-host optional-component downloads, ~340 MB and ~1.5 GB (C4, H1)
- per-host self-update under launchd / systemd (C5)

Environment surveyed on the local Mac (darwin arm64, 240 GB free): Docker 29.2 running with
buildx for linux/amd64 + linux/arm64, node 24.15, pnpm 11.9, uv, python3, JDK 17, Android SDK
with `Pixel_7` + `gp-e2e` AVDs (android-35 google_apis arm64), Playwright browsers cached,
cloudflared + ngrok, `claude` 2.1.220 on PATH, codesigning identity `Patch Self-Signed Test`
valid, `gh` authenticated (repo scope), ssh key present, `hetzner` reachable (Ubuntu 24, systemd
255 — production box, not a test target).

## 3. Things no environment can give the agent — call these out before the build starts

- Notarisation and a Developer ID Team ID. Self-signed works for install and for Squirrel, but
  a self-signed daemon artifact cannot be notarised, so A2's "notarised where the OS requires
  it" is only provable to the signature level unless the user supplies Apple credentials.
- A genuinely bare macOS machine other than a VM. `tart` is the closest honest substitute; a
  physical second Mac is not obtainable.
- A second physical machine on a different network. "Behind NAT with no public address" is
  provable only structurally (the daemon dials out, no listening port is opened) — the agent
  can assert no inbound socket is bound, but cannot prove traversal of a real hostile NAT.
- Real audible audio and a human voice for the voice device.
- Provider-side failure modes that need the provider to misbehave (Anthropic models endpoint
  returning non-2xx). These must be forced at the network layer rather than by mocking the
  daemon, since I1 forbids a mocked daemon.
