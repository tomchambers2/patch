## Environment-gated tests

Two host integration tests drive the GENUINE backend SDK and require a live,
non-expired `claude login` OAuth credential. They SKIP (rather than false-pass or
hard-fail) when no working login resolves — including when a resolvable token is
clock-expired:

- `daemon/real-backend.integration` — a real streamed completion + session id.
- `daemon/mcp-tools-real-sdk.integration` — a real agent calling patch MCP tools.

## Known gaps

- `15-design-mobile.md` (⚠️): `apps/mobile` ships with vitest component/store
  suites and a maestro flow suite. The host-shaped surfaces added by this change
  (Settings → Hosts, per-host components, host-scoped pickers) are not yet
  covered; group J1 rebuilds this index against the finished system.
- `18-tech-stack.md` (⚠️): stack/version choices are enforced by the
  toolchain (tsc/eslint), not runtime tests — there is nothing behavioural to
  assert beyond the build passing.
